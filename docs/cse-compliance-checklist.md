# CSE 合规自查清单

> 等保 2.0 三级 / PIPL / GDPR / 中国密码法 SM 系列等关键条款映射。

## 1. 加密算法合规

| 法规 | 要求 | 当前实现 | 是否满足 |
| --- | --- | --- | --- |
| 等保三级 | 数据传输 / 存储应使用国家认可加密算法 | AES-256-GCM | ⚠️ 需评估是否引入 SM4-GCM 双轨（按行业要求） |
| 商用密码法 | 涉密 / 关基行业必须使用国密算法 | 仅西密；可扩展 SM3/SM4 适配器 | ⚠️ 待人工评估业务范围 |
| GDPR Art.32 | "适当的技术措施"如加密 / 假名化 | AES-256-GCM + KEK 隔离 | ✅ |

## 2. 密钥管理

| 项 | 要求 | 实现 | 状态 |
| --- | --- | --- | --- |
| KEK 集中管理 | 物理 / 逻辑隔离 | DB 表 `cse_kek`，二次密码 + 审计 | ✅（业主确认威胁模型不含拖库） |
| KEK 备份 | 加密备份 + 恢复演练 | 导出 ZIP（PBKDF2 + AES-GCM） | ✅ |
| KEK 轮换 | 定期 / 事件驱动 | 后台菜单一键轮换 | ✅ |
| KEK 销毁 | 安全擦除 | `Arrays.fill(0)` after use | ✅ |
| 审计追踪 | 不可抵赖 | `cse_kek_audit_log` | ✅ |

## 3. 个人信息保护（PIPL / GDPR）

| 条款 | 要求 | 实现 |
| --- | --- | --- |
| PIPL §51 / GDPR Art.5(1)(c) 数据最小化 | 不存非必要 EXIF | `stripImageMetadata` 自动剥离 |
| PIPL §38 跨境传输 | 出境前评估 | OSS 桶部署区域可控；建议明文不出境 |
| GDPR Art.17 被遗忘权 | 用户注销可全删 | 配套删除 `oss_file` 行 + 桶内对象（脚本待补） |
| GDPR Art.32 完整性 | 防篡改 | AES-GCM AAD 绑定 fileId，不可篡改 |

## 4. 访问控制

- ✅ 401 / 403 闸门：`OssFileMetaService.canRead`
- ✅ 401 立即清缓存：`checkStatus + clearImageCache`
- ✅ 跨租户隔离：`tenant_id` 第一道闸
- ✅ 二次密码 + 审计：所有 KEK 管理操作

## 5. 待人工评估

- 业务领域是否属于等保三级 / 关基（金融 / 政务 / 医疗）→ 决定是否启用 SM 算法
- OSS 桶物理位置是否合规（PIPL 跨境）
- 隐私政策是否声明使用客户端加密 + 密文存储
- 第三方安全审计 / 渗透测试报告
- 数据泄漏应急响应预案（含 KEK 失窃场景）
